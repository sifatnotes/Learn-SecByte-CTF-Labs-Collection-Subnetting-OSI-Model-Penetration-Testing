## Introduction

Building a successful career in offensive security and network defense requires a rock-solid foundation in core networking models, IP addressing precision, Layer 2 switching mechanics, standardized pentesting methodologies, and practical capstone execution. Hosted on [Learn SecByte](https://learn.secbyte.org/), this foundational-to-advanced networking and penetration testing collection provides comprehensive, practical training to bridge theoretical computer science concepts with hands-on technical tradecraft.

From mastering complex IPv4 subnetting calculations and variable-length subnet masks (VLSM) to dissecting the OSI/TCP-IP layers from bits to breaches, analyzing Ethernet frame structures and ARP cache updates, auditing Android/iOS mobile application attack surfaces, and executing end-to-end full-scope penetration tests with professional report drafting, these exercises establish core operational readiness.

   - [Introduction to Computer Networks: From Packets to Security A...](https://learn.secbyte.org/ctf/introduction-to-computer-networks-from-packets-to-security-a)
   - [Network Fundamentals and Architecture](https://learn.secbyte.org/ctf/network-fundamentals-and-architecture)
   - [Understanding the OSI Model: From Bits to Breaches](https://learn.secbyte.org/ctf/understanding-the-osi-model-from-bits-to-breaches)
   - [TCP/IP Model Explained](https://learn.secbyte.org/ctf/tcpip-model-explained)
   - [Ethernet Fundamentals: Frames, MACs, and Switching](https://learn.secbyte.org/ctf/ethernet-fundamentals-frames-macs-and-switching)
   - [MAC Addresses and ARP: Layer 2 Fundamentals](https://learn.secbyte.org/ctf/mac-addresses-and-arp-layer-2-fundamentals)

2. **Phase 2: IPv4 Addressing Precision & Advanced Subnetting** — Calculate IP subnet boundaries, host ranges, and complex VLSM allocations:
   - [IPv4 Addressing and Subnetting Mastery](https://learn.secbyte.org/ctf/ipv4-addressing-and-subnetting-mastery)

4. **Phase 4: Pentest Methodologies, Reporting & Full-Scope Capstone** — Perform real-world CTF challenges, master professional report writing, and complete the final capstone assessment:
   - [CTF Labs: Real-World Practice](https://learn.secbyte.org/ctf/ctf-labs-real-world-practice)

## How to Use the Labs

1. Select a challenge link from the index or category sections above.
2. Read the scenario directives, network specs, and target parameters on [Learn SecByte](https://learn.secbyte.org/).
3. Deploy analysis toolsets (Wireshark, ipcalc, Nmap, Burp Suite, Jadx, apktool, Metasploit, Python) inside an isolated workstation.
4. Solve subnetting math challenges, analyze Ethernet frame headers, decompile mobile binaries, execute penetration testing phases, author vulnerability reports, and capture target flags.
